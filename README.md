# Centro Socialista

Landing page estática, preparada para publicação no GitHub Pages. A página inicial é [index.html](./index.html), usa a estrutura do tema Start Bootstrap Clean Blog e recebe os ajustes visuais de [styles.css](./styles.css).

## Publicação no GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/(root)`. Não é necessário executar um processo de build; o GitHub Pages publica os arquivos da raiz após cada atualização da branch.
